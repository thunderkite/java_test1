# ShareLane UI tests

This project contains end-to-end UI tests for the [ShareLane](https://www.sharelane.com/) demo bookstore. The tests are written in Java with JUnit 5 and Selenium WebDriver.

## Requirements

- JDK 17 or newer
- Apache Maven 3.9 or newer
- Google Chrome
- Internet access from the test machine

Selenium Manager downloads and configures the matching ChromeDriver automatically when the test starts.

## Run the tests

Run the complete test suite from the project root:

```shell
mvn test
```

The suite opens a real Chrome browser and uses the live ShareLane website. The test creates a temporary account, adds **White Fang** to the shopping cart, and verifies the checkout details.

## Notes

- These are live end-to-end tests, so they require an available ShareLane service and may be affected by network or site changes.
- A Chrome window is opened during the test. Make sure Chrome can start in the current environment before running `mvn test`.
- The test data is generated by the registration flow, so no credentials need to be configured locally.

## Project layout

```text
src/test/java/pages/  Page objects used by the tests
src/test/java/tests/  JUnit test cases
pom.xml               Maven dependencies and test configuration
```
